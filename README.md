# Ludo Rush — Web Preview

Public repo for Flutter **web** preview on GitHub Pages.

## Live URL
https://gamedevraj3-ctrl.github.io/ludo-web-preview/

## One-time setup (phone OK)
1. Download **Ludo_Flutter_Web_Preview.zip** from chat
2. Extract → open the **web** folder
3. On this repo → **Add file → Upload files**
4. Upload **everything inside web/** to the **root** of this repo  
   (`index.html` must be at repo root, not inside another `web/` folder)
5. Commit
6. **Settings → Pages → Deploy from a branch → main → / (root) → Save**
7. Open: https://gamedevraj3-ctrl.github.io/ludo-web-preview/

## Note
GitHub connector cannot reliably push multi‑MB binary files (CanvasKit `.wasm`).  
Upload once via the website; after that only changed assets need re-upload.
